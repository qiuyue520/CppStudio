工具链，一条不少。

1.0 克隆· 2.0 编辑· 3.0 构建· 4.0 运行

1.0 · 克隆

把仓库放进手机，或者从模板开始。

从 GitHub、Gitee、GitLab 克隆 C/C++ 项目——HTTPS、SSH、Token、GitHub OAuth 设备码都可以登录，克隆完成自动导入最近项目。根目录有 CMakeLists.txt（或 Makefile）就能打开，工程在子目录里也会自动找一层。

从零开始同样就绪：C++ Hello、C Hello、命令行工具、静态库、单元测试、多线程、SQLite、SDL2 窗口八种模板，创建即生成 CMakeLists.txt、.clang-format 与 .gitignore。

2.0 · 编辑

clangd 接住每一次按键。

官方语言服务 clangd 完整接入：补全、参数提示、符号高亮、实时诊断、悬浮提示、跳转定义、格式化。它读 CMake 导出的 compile_commands.json，所以补全是语义级的，不是关键字猜的。

Sora 编辑器提供标签页、文件树、文件内与全项目搜索、结构大纲——一套为触屏优化的编辑体验。

3.0 · 构建

构建发生在手机上，不在云端。

proot + Alpine rootfs 在设备上提供完整的 C/C++ 工具链——build-base、cmake、pkgconf、clang、gdb、git 开箱内置，无需 root 权限，也不依赖云端。构建目录固定为 build/，配置时顺手导出编译数据库。

C/C++ 没有 go get，所以有「库管理」：40+ 精选库一键 apk 安装，卡片直接给出 CMake 接法；也支持在 Alpine 仓库里按包名搜索任意包。

4.0 · 运行

写完即运行，不必先打包 APK。

点「运行」，CppStudio 找到构建产物就在终端里启动它——scanf、std::cin 这些标准输入照样能交互，运行参数可以在项目配置里写死。

CMake 项目点「测试」走 ctest，Makefile 项目走 make test；构建、测试与工具链日志统一收进输出面板，跑偏了随时停。

插件是数据，不是代码。

一个 manifest.json 加一个能力目录，就是插件的全部结构——不执行任何代码。当前支持 AI 技能（skills/）与工作区小工具（tools/）扩展，templates/ 与 themes/ 已预留。

在插件市场一键安装，或把目录打成 ZIP 本地导入；装完即用，可随时禁用或卸载。
